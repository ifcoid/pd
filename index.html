Fitur Lengkap pd: Reader Teringan & Utilitas Dokumen

Dirancang sederhana, berkecepatan tinggi, dan 100% offline demi keamanan total dokumen Anda.

📖

View PDF & Export ke PNG/JPG

Membuka dan membaca dokumen PDF secara instan tanpa runtime berat (100% Rust murni, zero C++ / Electron). Navigasi halaman cepat, kontrol zoom halus, serta ekspor halaman PDF ke gambar PNG atau JPG dalam satu klik.

🖼️

Gambar ke PDF (Images to PDF)

Konversi satu atau kumpulan file gambar (PNG, JPG, JPEG, WEBP, BMP) menjadi satu dokumen PDF utuh. Mendukung pengurutan halaman gambar dengan kualitas dan dimensi asli yang terjaga.

📑

Merge PDF (Penggabungan)

Gabungkan beberapa dokumen PDF terpilih menjadi satu dokumen rapi. Mendukung pengurutan naik-turun dan renumbering objek internal yang bersih dan valid.

✂️

Split & Ekstraksi Halaman

Deteksi otomatis total halaman. Pisahkan halaman dengan fleksibel menggunakan format rentang seperti 1-5 atau nomor terpisah seperti 1, 3, 5.

🗜️

Kompresi Objek Modern

Kecilkan ukuran file dengan kompresi stream Flate internal dan pengemasan PDF 1.5 Object Streams (/ObjStm) serta pembersihan metadata orphaned.

🔒

Privasi 100% Terjaga

Tidak ada dokumen yang dikirim ke cloud. Semua pemrosesan berlangsung sepenuhnya di CPU/RAM lokal komputer Anda tanpa memerlukan koneksi internet.

🚀

Performa Native Pure-Rust

Aplikasi desktop sejati tanpa overhead memory Electron. Ditenagai oleh engine CPU rasterizer SIMD dan framework Iced yang ringan, responsif, dan hemat daya.
